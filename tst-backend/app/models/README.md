# Models (Data Persistence) 🗄️

Este diretório contém a representação fiel das estruturas de dados que serão persistidas permanentemente no sistema (Banco de Dados).

### Responsabilidades:
*   **Mapeamento de Dados**: Definição de tabelas, colunas e tipos de dados.
*   **Relacionamentos**: Configuração de chaves estrangeiras e vínculos entre entidades.
*   **ORM**: Implementação de classes utilizando ferramentas como SQLAlchemy, SQLModel ou Tortoise.
*   **Migrações**: Base para a geração de versionamento de banco de dados.
