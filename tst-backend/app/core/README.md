# Core Module (Configuration & Infrastructure) ⚙️

O diretório `core` centraliza as configurações fundamentais que permitem que a aplicação suba e funcione corretamente em diferentes ambientes.

### Responsabilidades:
*   **Configurações**: Gerenciamento de variáveis de ambiente e arquivos `.env`.
*   **Segurança**: Definição de políticas de CORS, hashing de tokens e criptografia.
*   **Constantes Globais**: Definição de metadados da aplicação (versão, nome, descrição).
*   **Setup de Infraestrutura**: Inicialização de clientes de conexão e logs do sistema.
